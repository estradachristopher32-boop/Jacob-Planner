# 💪 Jacob's Meal Planner

A comprehensive weekly meal planner, grocery list generator, and calorie tracker designed specifically for Jacob's bulk phase! This is a simple, easy-to-use web application that runs entirely in your browser - no coding knowledge required!

## 🌟 Features

- **📅 Weekly Meal Planning**: Plan your meals for the entire week with detailed macros
- **🛒 Smart Grocery Lists**: Automatically generate shopping lists from your meal plans
- **📊 Calorie Tracking**: Log and track your daily calorie intake
- **💾 Auto-Save**: All your data is saved automatically in your browser
- **📱 Mobile Friendly**: Works great on phones, tablets, and computers
- **🌙 Dark Mode Support**: Easy on the eyes during late-night meal prep
- **📄 Print Ready**: Print your meal plans and grocery lists
- **🔌 Works Offline**: Access your plans even without internet (PWA)

## 🚀 How to Access

The site is published on GitHub Pages at:

**https://estradachristopher32-boop.github.io/Jacob-Planner/**

Just open that link in any web browser (Chrome, Safari, Firefox, Edge, etc.)!

## 📱 How to Use

### Adding Meals
1. Click the **"➕ Add Meal"** button
2. Fill in the meal details:
   - Name (e.g., "Chicken & Rice Bowl")
   - Day of the week
   - Meal type (Breakfast, Lunch, Dinner, Snack)
   - Calories and macros (Protein, Carbs, Fats)
   - Ingredients (optional, but useful for grocery lists!)
3. Click **"Add Meal"** to save

### Generating Grocery Lists
1. Add your meals for the week first
2. Click the **"🛒 Generate List"** button
3. Your grocery list will be automatically created from all meal ingredients
4. Check off items as you shop!

### Tracking Calories
1. Click the **"📊 Log Calories"** button
2. Select the date and enter your total calories for the day
3. Add optional notes about how you felt
4. Track your progress over time

### Tips for Jacob
- **For Bulking**: Aim for about 3,500 calories per day (300-500 calorie surplus)
- **Protein Goal**: Try to get 1g of protein per pound of body weight
- **Meal Prep**: Plan and prep on Sundays for the whole week
- **Stay Consistent**: The key to a successful bulk is consistency!

## 🔧 Local Development

If you want to test the site locally:

1. Clone this repository
2. Navigate to the `docs/` folder
3. Open `index.html` in your web browser
4. Or run a simple local server:
   ```bash
   cd docs
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`

## 📁 Files in This Repository

- **`docs/index.html`** - The main application
- **`docs/manifest.json`** - PWA configuration
- **`docs/sw.js`** - Service worker for offline support
- **`docs/icon-192.svg`** & **`docs/icon-512.svg`** - App icons
- **`docs/jacob_plan.json`** - Sample meal data with tips
