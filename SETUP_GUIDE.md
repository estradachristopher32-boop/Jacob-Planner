# GitHub Pages Setup Instructions

Follow these simple steps to make Jacob's Meal Planner live on the web!

## Step 1: Enable GitHub Pages

1. Go to your repository on GitHub: https://github.com/estradachristopher32-boop/Jacob-Planner

2. Click on **Settings** (near the top of the page)

3. In the left sidebar, click on **Pages**

4. Under "Build and deployment":
   - **Source**: Select "Deploy from a branch"
   - **Branch**: Select `main` from the dropdown
   - **Folder**: Select `/docs` from the dropdown
   - Click **Save**

5. Wait 1-2 minutes for GitHub to deploy the site

6. Refresh the Pages settings page - you should see a message like:
   > "Your site is live at https://estradachristopher32-boop.github.io/Jacob-Planner/"

## Step 2: Visit Your Site!

Open this URL in any web browser:
**https://estradachristopher32-boop.github.io/Jacob-Planner/**

## Step 3: Start Using It!

- Add meals with "➕ Add Meal"
- Generate grocery lists with "🛒 Generate List"
- Log daily calories with "📊 Log Calories"
- All data saves automatically in your browser!

## Optional: Add to Home Screen (Mobile)

On iPhone:
1. Open the site in Safari
2. Tap the Share button (square with arrow)
3. Scroll down and tap "Add to Home Screen"
4. Tap "Add"

On Android:
1. Open the site in Chrome
2. Tap the three-dot menu
3. Tap "Add to Home screen"
4. Tap "Add"

Now you have a quick-access app icon! 💪

## Troubleshooting

**Site not loading?**
- Make sure you waited 1-2 minutes after enabling Pages
- Check that the branch is set to `main` and folder is `/docs`
- Try clearing your browser cache or using incognito mode

**Lost your data?**
- Data is stored in your browser's local storage
- If you clear browser data/cookies, your meal plans will be lost
- Consider taking screenshots or printing your plans regularly

**Need help?**
- Open an issue on GitHub
- Or just ask for help! 😊
